# API

## `init_systemd_logging(*, logger=None, syslog_id='')`

Attaches `SystemdHandler` to a given logger (root logger by default).
Returns True if initialization went fine.

* `logger` — a Logger instance to attach the handler to.
* `syslog_id` — custom syslog identifier (SYSLOG_IDENTIFIER journal field).

## `check_for_systemd()`

Returns True if the current system is run by systemd.

When the `JOURNAL_STREAM` environment variable is set, it is verified against the actual
stdout/stderr descriptors (so wrapping processes which replaced the streams are detected);
otherwise the `INVOCATION_ID` environment variable is used.

## `log_message(*, level, msg, context=None)`

Sends a log record directly into systemd journal. Returns True on success.

* `level` — logging level (e.g. `logging.DEBUG`).
* `msg` — message text.
* `context` — additional fields to attach to the journal record.

## `SystemdHandler`

Standard logging handler writing to systemd journal.

## `SystemdFormatter`

Formatter used by `SystemdHandler` to compose journal fields.
